# Code Review Checklist

## Architecture

- Architecture preserved
- Folder structure preserved
- API contract unchanged

## Code Quality

- Readable
- Minimal changes
- No duplicated code
- Existing style preserved

## Verification

- Build passes
- Lint passes
- No TypeScript errors

## Scope

- Only approved files changed
- No unrelated refactoring
- No unnecessary dependency changes

## Documentation

- Report provided
- Risks documented
- Breaking changes documented

## Approval

A task is approved only if every checklist item passes.
